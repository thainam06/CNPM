## Cập nhật an toàn cho kho JSON

- Bộ mẫu mở rộng có tám điểm; React tiếp tục nhận danh sách từ API.
- Migration `SampleDataVersion = 7` chỉ xét ba tên bổ sung, bỏ qua bản ghi Quận 1 đã tồn tại cùng tên kể cả khi đang ẩn.
- Giữ nguyên các bản ghi, tài khoản, vai trò, menu và tombstone cũ; ID mới lớn hơn mọi ID đang có/đã xóa và không nhỏ hơn `NextPlaceId`.
- Ghi kho theo cơ chế snapshot và thay file nguyên tử hiện có. Chỉ tăng catalog version khi thực sự thêm điểm.
- Khi migration hoàn tất, khởi động lại không thêm trùng; điểm mới bị Admin xóa sau đó không tự xuất hiện lại.
- Không ghi đè `platform.json` bằng file seed thủ công. Không commit dữ liệu `App_Data`, MP3 thử, ảnh kiểm tra, token hoặc thông tin tài khoản.

## Giao diện

Lưới desktop chuyển thành bốn cột; màn hình hẹp chuyển ba/hai/một cột theo breakpoint. Ảnh lớn hơn, tên địa điểm rõ hơn; thêm thanh liên kết ba bước chọn điểm → nghe → bản đồ, số kết quả/tổng số và nút xóa bộ lọc. Màu cam–kem–nâu nhạt, Admin và các xử lý audio hiện có được giữ.

Trình nghe ưu tiên `GET /api/narration/pack-manifest` để lấy nội dung và MP3 đã chuẩn bị cho đúng khóa nguồn/ngôn ngữ/revision. Khi tải MP3 sẵn có, frontend kiểm tra byte và SHA-256 trước khi cache. Nếu chưa có asset thì tiếp tục POST dịch/tạo speech hiện có. Không tăng quota hoặc tắt rate limiter. Lượt tạo hàng loạt qua API công khai gặp 429; đã dùng hàng đợi Admin đúng quyền để tạo đủ nội dung.

## Kiểm chứng

- `dotnet build --no-restore`: thành công, 0 warning, 0 error.
- `dotnet test --no-build`: **109/109 đạt** khi chạy với quyền môi trường thông thường. Lần chạy trong sandbox có 9 lỗi môi trường liên quan Windows Event Log/DataProtection; không sửa code để vô hiệu hóa bảo vệ.
- `npm.cmd run lint`: sạch; `npm.cmd test`: **37/37 đạt**, có thêm ba ca kiểm tra khóa nguồn/ngôn ngữ/revision, checksum và hủy tải; build production thành công. Vẫn có cảnh báo kích thước chunk MapLibre đã tồn tại.
- HTTP thực `/api/places`: tám điểm; ba điểm mới có hai ảnh và bài Việt 1041/1120/1056 ký tự tại thời điểm kiểm tra. ID kho đang dùng là 10/11/12; không dùng các ID này như hằng số trong frontend.
- Kết quả kiểm tra MP3 thật và ảnh chụp giao diện được lưu tại `artifacts/places-expansion-20261020/`; thư mục này được Git ignore. Phân biệt test logic với kiểm thử phát audio thật và thử đi bộ ngoài thực địa.
- Ba tác vụ Admin hoàn tất 6/6 ngôn ngữ mỗi điểm. GET và checksum **18/18 đạt**; ffprobe **18/18 có codec MP3**, thời lượng khoảng 57–72 giây. Nội dung ngoại ngữ khác nguồn Việt, provider SmartTourDraft. Kiểm tra này không xác nhận chất lượng phát âm/ngữ nghĩa như chuyên gia bản ngữ.
- Browser thực: tìm không dấu `tao dan` ra đúng điểm; Tao Đàn Việt 61,584 giây và Anh 56,832 giây đều phát với `readyState = 4`, `paused = false`, không lỗi giải mã; dừng và chuyển ngôn ngữ loại bỏ audio cũ.

Các báo cáo năm địa điểm trước thời điểm mở rộng vẫn là tài liệu lịch sử; khi nộp báo cáo cuối cần cập nhật phạm vi thành tám địa điểm.
